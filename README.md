# strapi-import-tools

Plugin potente para Strapi que permite importar y exportar datos en formato CSV con una interfaz moderna y amigable.

## Características

- **Importar datos** - Carga masiva de contenido desde archivos CSV
- **Exportar datos** - Descarga tu contenido en formato CSV para backup o análisis
- **Interfaz intuitiva** - Drag & drop para cargar archivos
- **Validación integrada** - Validación automática de datos
- **Soporte para múltiples tipos de contenido** - Funciona con todos tus content types

## Instalación

```bash
npm install strapi-import-tools
```

## Configuración

Después de instalar, el plugin estará disponible en el panel de administración de Strapi en el menú lateral.

## Uso

### Importar datos

1. Ve a la sección "Import/Export" en el panel de administración
2. Haz clic en "Start Import"
3. Selecciona tu archivo CSV (arrastrándolo o explorando)
4. Revisa los datos y confirma la importación

### Exportar datos

1. Ve a la sección "Import/Export" en el panel de administración
2. Haz clic en "Start Export"
3. Selecciona los content types que deseas exportar
4. Descarga el archivo CSV generado

## Requisitos

- Strapi 5.x o superior
- Node.js 16+
